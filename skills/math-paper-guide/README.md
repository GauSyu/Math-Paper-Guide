# 论文导读 · math-paper-guide

以逻辑关系图组织数学论文导读，保留原文术语、符号和结果编号，解释证明连接、前人研究及引文用途。完整导读默认交付本地交互式网站、所需资源和可编辑源码，也支持指定的其他格式。网站围绕论文及其论证组织，不默认采用课程、学习任务或进度管理体系；视觉设计、导航与交互可按导读需要选择。

## 导读方法

根据原文的 statements、hypotheses 和 proof passages 确定连接，附上可回查的定位；外部结果核查同时记录引用处和被引用结果的位置。已有同版本索引可以用于导航；只有确实需要全篇或多篇结果与显式引用清单时，才考虑额外抽取。缺少来源或检查工具时，明确缺失内容和未完成的核查，保留可完成的导读部分。

逻辑图先呈现主要结果及其输入，再沿重要连接解释各个输入解决的障碍、所需假设及具体用途。前人研究与背景引文放在相应语境中；只有实际用于论证的结果才画成 proof dependency。节点、解释和原文定位保持一致。

## 网站交付

默认交付本地网站的入口 HTML、所需资源和可编辑源码。节点选择、局部展开、搜索与原文跳转用于阅读论文；导读保持完整的文字阅读路线，关键条件与未核查部分不能只藏在悬浮提示中。

本地交互应在保存后独立运行。复杂公式所需的资源要随网站交付，或明确说明外部依赖。无法实际运行浏览器时，应说明尚未测试的页面行为。

只有用户明确要求 Sites 私有托管，且具有相应能力时，才使用 ChatGPT Sites 的私有托管流程；核对私有访问范围，并保留本地网页和可编辑源码。制作、预览或保存网站本身不请求注册、源码上传或部署。
